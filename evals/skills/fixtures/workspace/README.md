# notes-app

Small React + TypeScript notes application used as a fixture for skill-routing evaluations.

- `src/notes.ts` — pure state transitions for notes
- `src/checkout-form.tsx` — the upgrade checkout form
- `src/sync/` — background sync with retries, caching, and feature flags
- `src/legacy/` — code ported from the old billing service, untested
- `docs/story.md` — the current story under discussion
