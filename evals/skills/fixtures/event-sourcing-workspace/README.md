# purse

Prepaid wallets for the shop. **The wallet ledger is event sourced.**

The domain glossary is in `docs/glossary.md`. Code lives under `src/`; nothing of the
wallet ledger has been written yet.

- `pnpm test` runs the suite once; `pnpm test:watch` keeps it running.
- `pnpm typecheck` runs `tsc --noEmit`.
